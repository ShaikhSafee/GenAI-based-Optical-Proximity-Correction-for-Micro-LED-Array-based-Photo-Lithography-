# Generative AI Assisted Micro LED Direct Write Maskless Photolithography for MEMS Fabrication

Welcome to the official project repository for our entry in the IEEE International Electron Devices Society MEMS Student Challenge. This project introduces an adaptive maskless photolithography framework that combines generative machine learning models with precision micro-display hardware to fabricate custom micro-electromechanical structures without physical photomasks.

## Hardware and AI Scale Boundary

Modern generative AI models and industrial photolithography optimizers rely on massive deep learning architectures that scale to billions of parameters. During training, parameter count directly dictates the compute memory and execution footprint required to model spatial cross-talk, wave diffraction, and multi-layer intensity matrices across realistic wafer surfaces.

Every parameter in a neural network requires dedicated storage for its weight, momentum, and gradient states during backpropagation. Training an unoptimized, full-scale generative model across thousands of high-resolution layout frames requires hundreds of gigabytes of high-bandwidth memory (HBM). A standard consumer desktop graphics card typically maxes out at 8 to 24 gigabytes of VRAM. Attempting to execute full iterative training for billion-parameter models on standard PC hardware results in instantaneous out-of-memory errors or severe memory swapping bottlenecks.

Industrial optical proximity correction engines bypass standard PC hardware by distributing matrix multiplication across dedicated server clusters containing hundreds of enterprise accelerators connected over ultra-fast interconnects. Because enterprise training hardware is beyond the scope of local lab setups, this system bridges the gap using edge-optimized deployment strategies.

To run this system on accessible equipment, training is decoupled from local hardware execution. We train a lightweight, focused UNet architecture using physics-informed optical loss functions on isolated synthetic masks. Once trained, the model weights are exported as a compiled inference engine. This allows local PCs or embedded microcontrollers like the ESP32 to run real-time inference and pattern streaming without needing supercomputer-level compute resources.

## System Design and Execution

The setup operates across three primary stages to transform digital designs into physical micro-structures:

The software and AI layer accepts target geometries such as interdigital transducers or micro-cantilevers. A custom PyTorch model processes the target image and predicts the exact pre-distorted exposure array needed to counter optical diffraction. The model includes a physics-informed loss function that mathematically models light spreading through a microscope objective via a Gaussian Point Spread Function.

The embedded control layer translates corrected layout matrices into physical light signals. Pre-distorted patterns are converted into quantized 8-bit array streams. An ESP32 microcontroller accepts these raw streams over high-speed SPI and drives the individual elements of a UV micro-LED display array with millisecond-level exposure timing.

The optical exposure layer projects pattern maps onto wafer substrates. Emitted UV light passes through a reduction lens assembly onto silicon or glass substrates coated with photoresists like SU-8. An integrated machine vision loop uses OpenCV to track wafer alignment markers and adjust for positional errors before triggering the UV exposure array.

## Simulation Dashboard and Results

The simulation dashboard illustrates the end-to-end performance of the Generative AI Optical Proximity Correction engine compared to conventional direct maskless projection.

### Interface Sections

* **Design Input & Optical Setup:** Displays the binary target mask alongside adjustable fabrication process parameters, such as resist thickness and Micro-LED pixel pitch.
* **GenAI Optical Proximity Correction Engine:** Shows the pre-distorted exposure heatmap generated by the neural network. Bright yellow regions represent intentional over-exposure at sharp corners to counter diffraction-induced intensity loss.
* **Exposure & Post-Processing Simulation:** Features a direct visual comparison between conventional and AI-corrected exposures:
* **Uncorrected (Top Right):** Direct pixel mapping causes severe optical cross-talk, resulting in rounded corners and significant Critical Dimension (CD) errors.
* **With GenAI OPC (Bottom Right):** The pre-distorted pattern yields sharp, rectangular feature profiles with minimal CD error on the developed resist.



# Quantitative Metrology Performance

The dashboard summarizes the improvement in pattern fidelity metrics across key parameters:

* **Corner Rounding Radius:** Reduced from **4.8 µm** (uncorrected) down to **0.6 µm** with GenAI OPC.
* **Line-Edge Roughness (LER, 3σ):** Improved from **145 nm** down to **21 nm**.
* **Overall Fidelity Improvement:** Achieves an overall **88%** increase in pattern fidelity.
